## Getting Started

Chrisbot is a WhatsApp bot created for Christian's specific purposes, for example, to send a message to a group of friends, remind groups of friends about a pending payment, etc.

## Stack

- [Node.js](https://nodejs.org/en/)
- [TypeScript](https://www.typescriptlang.org/)
- [BuilderBot](https://www.builderbot.app/en)
- [NGROK](https://ngrok.com/)
- [Express](https://expressjs.com/)
- [Raspberry Pi](https://www.raspberrypi.org/)

## How to use

1. Clone the repository
2. Install the dependencies with `npm install`
3. Create a `.env` file from the `.env.example` file and fill in the necessary information.
4. Run the project with `npm run dev`
